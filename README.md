# آورورا — فروشگاه تخصصی گیمینگ

یک فروشگاه اینترنتی کامل و فارسی (RTL) در حوزه‌ی گیمینگ، ساخته‌شده با **React + Vite + Tailwind CSS v4**. این پروژه فقط یک لندینگ نیست: جستجو، فیلتر هوشمند، صفحه محصول، سبد، چک‌اوت چندمرحله‌ای، حساب کاربری، علاقه‌مندی، پشتیبانی و پنل مدیریت را شامل می‌شود.

## اجرا

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # خروجی پروداکشن در dist/
```

## صفحات

| مسیر | توضیح |
| --- | --- |
| `/` | صفحه اصلی: هیرو اسلایدر، دسته‌ها، کاروسل‌های جدیدترین/پرفروش/بازی‌ها، استور دیجیتال، برندها، اخبار |
| `/products` | همه‌ی محصولات با فیلتر و مرتب‌سازی |
| `/category/:id` | دسته‌بندی با فیلترهای اختصاصی همان دسته (بر اساس `FILTER_DEFS`) |
| `/product/:id` | صفحه محصول: گالری، مشخصات گروه‌بندی‌شده، شفافیت قیمت (منبع + تاریخ)، نظرات با توزیع امتیاز، محصولات مرتبط |
| `/search` | جستجو با پیشنهاد زنده (محصول/دسته/برند)، جستجوهای اخیر و پرطرفدار |
| `/cart` `/checkout` | سبد خرید و چک‌اوت ۵ مرحله‌ای (حساب، آدرس، ارسال، پرداخت، تأیید) |
| `/login` `/register` | فرم + اسلایدر نمایشگر گیمینگ (دو ستونه در دسکتاپ، مینیمال در موبایل) |
| `/account/**` | داشبورد، سفارش‌ها، آدرس‌ها، خریدهای دیجیتال (کدها)، تیکت‌ها، اعلان‌ها، امنیت |
| `/support` | سوالات متداول، موضوعات کمک، ثبت تیکت |
| `/admin` | پنل مدیریت نمایشی: ویرایش قیمت/موجودی با ذخیره‌ی محلی، مشاهده‌ی منبع و تاریخ قیمت، سفارش‌ها و تیکت‌ها |

## معماری داده و سیاست قیمت‌گذاری

- همه‌ی محصولات در `src/data/` با ساختار واحد تعریف شده‌اند: `price` شامل `final` (تومان)، `source`، `sourceUrl`، `lastChecked` و در صورت دلاری بودن `sourcePrice + sourceCurrency + exchangeRate`.
- **قیمت حدسی وجود ندارد.** محصولاتی که قیمت معتبر برایشان پیدا نشد با وضعیت «استعلام قیمت» نمایش داده می‌شوند (`INQ()` در `src/data/meta.js`).
- قیمت‌های دلاری (گیفت‌کارت‌ها و پیش‌خرید رسمی مثل GTA VI) با نرخ مستند `FX` در `meta.js` تبدیل شده‌اند؛ نرخ، منبع نرخ و کارمزد در خود محصول ذخیره و در صفحه محصول نمایش داده می‌شود.
- پنل مدیریت می‌تواند قیمت/موجودی را بازنویسی کند (`overrides`) — در معماری واقعی این لایه به بک‌اند/DB متصل می‌شود و ساختار داده از حالا برای آن آماده است.

## وضعیت تصاویر

تصاویر بنر/هیرو و بخشی از محصولات تولید داخلی پروژه هستند (مسیر `public/img/`). تولید تصویر محصول به‌صورت مرحله‌ای انجام می‌شود؛ محصولاتی که تصویرشان هنوز آماده نباشد با حالت جایگزین تمیز نمایش داده می‌شوند تا هیچ‌وقت تصویر شکسته دیده نشود. جلد بازی‌ها تایپوگرافیک است تا از کاورهای دارای حق نشر استفاده نشده باشد.

## نکات فنی

- فونت: **Vazirmatn** (لوکال، `public/fonts`)
- آیکون‌ها: **Lucide** (بدون ایموجی در ناوبری)
- اسلایدرها: **Embla** با اتوپلی، توقف در هاور، سوایپ لمسی و سازگار با RTL
- ناوبری موبایل: نوار پایین شیشه‌ای (backdrop-blur) با ناحیه‌ی امن (safe-area)
- حالت‌های بارگذاری (اسکلتون)، خالی و خطا برای همه‌ی صفحات اصلی پیاده شده است.
- پرونده‌ی قدیمی «Aurora Chat» دست‌نخورده در `legacy/aurora-chat/` نگهداری می‌شود.
